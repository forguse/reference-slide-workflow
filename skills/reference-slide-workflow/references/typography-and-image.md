# Typography in relation to images

Read this when the reference's character depends on expressive type, editorial small text, mixed scripts, vertical writing, or type crossing image boundaries. Typography is a composition system, not just a list of installed font names.

## Extract the reference's decisions

For representative pages, record each text role: display title, section title, prose, caption, marginal note, numeral, quotation, or small navigational label. For each role capture the family/letterform character, weight, width, size, tracking, leading, orientation, alignment and relationship to the image. Distinguish font families from sizes and weights of one family. A screenshot supports an observed character and confidence level, not a certain font identification.

Record spatial relationships explicitly: aligned to a picture edge; following an architectural axis; sitting in a quiet area of the photograph; crossing the boundary between image and ground; paired with a detail crop; or intentionally separated as a marginal note. Explain what the move does for reading. Do not copy the source's distinctive wording, letter artwork, or collage as a substitute for independently composing the new material.

## Choose a repertoire, not a fixed font count

There is no universal one-font or two-font limit. The reference and page job determine the number. A scientific evidence page may need a restrained set; an editorial or cultural page may need several contrasting families. Conversely, do not add fonts just because an expressive reference exists. Each additional family needs a distinct communicative or compositional role.

Define the deck's available type roles and allow each page to select the subset it needs. Consistency means that recurring roles and contrasts remain recognizable, not that every page uses the same number of families or identical title placement. Record deliberate page-specific variations in the style profile. For synthesis from multiple references, choose a coherent new repertoire rather than collecting every source's font treatment.

Small text can establish rhythm and reward close reading: object names, locations, captions, short parallel phrases and editorial side notes. Give it real content. Do not fake sophistication with meaningless English, arbitrary scattered letters or an unreadable paragraph. Set size and contrast for the intended viewing mode; core claims and essential evidence must remain legible in presentation view. Compact secondary notes may be smaller in a reading-oriented deck.

## Compose with the photograph

Use the visible subject, light, direction and negative space to place type. Choose a crop that supports both the photograph and the words. Horizontal/vertical contrast, large/small contrast and serif/sans contrast are separate tools; do not apply all of them mechanically to every page. Chinese vertical writing needs intentional punctuation and column order; stacking characters is suitable for short display labels, not a substitute for proper long-form vertical typesetting.

Shared-edge alignment is a default for comparable peer modules, not a ban on editorial composition. Declare intentional offsets, inset labels or image/type overlaps with a local reason and appropriate bounds. Maintain ordinary alignment checks elsewhere. Never increase a global tolerance or waive all overlaps to excuse a poorly placed element.

## Select usable, licensed fonts

Verify actual family and style names, supported glyphs and weights, and the permission needed for the intended delivery (use, embedding, or redistributing font files). Save the official license alongside redistributed fonts. Select a documented alternative when the reference font is unknown or unavailable; compare its stroke contrast, character width, punctuation, numeral shape and line length in a rendered pilot. A similarly named font is not necessarily a visual match.

Keep text editable where the converter supports it. Inspect the real PPT render for fallback, synthetic weights, line reflow, vertical placement and lost tracking. If the export cannot express a key treatment, revise that treatment or use a supported representation and document the consequence; do not silently deliver flattened body text.

## Inspect the result

Review the cover and the hardest mixed-type/image page at presentation scale and close-up. Check the intended reading order, font role continuity, balanced visual weight, image subject clearance, small-text contrast, crop/caption correspondence and optical spacing. A geometric pass alone cannot establish expressive quality.

Suggested optional profile fields: `type_relationships` (role, page family, placement, image anchor, purpose), `page_type_variations` (page, roles used, reason), `font_sources` (actual family/style, official source, license, local file), and `substitutions` (reference observation, chosen match, visual consequence). These are design records, not slide copy.
